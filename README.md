# Despacho

Programa interno para la gestión del despacho.

## Descarga

El ejecutable `Despacho.exe` está en la sección **Releases** de este repositorio.

## Instalación

1. Descarga `Despacho.exe` desde *Releases*.
2. Cópialo a la carpeta del programa en el NAS (o al equipo donde se vaya a usar).
3. Ejecútalo. Al iniciarse, crea automáticamente sus carpetas de trabajo (`datos`, `Copias`, `DespachoVentana`...).

## Qué NO está en este repositorio

Por privacidad, nunca se suben:

- `datos/` y `Copias/`: datos y copias de seguridad del despacho.
- `DespachoVentana/`: perfil del navegador del programa (cookies, sesiones).
- `usuario.txt`, `carpeta.txt`, `tareas-avisadas.json`, `no-abrir-al-iniciar.txt`: ajustes de cada equipo.

## Nota

Solo se conserva el ejecutable compilado; el código fuente original no está disponible.
